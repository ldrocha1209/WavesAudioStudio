# Privacy

Waves runs locally. It has no accounts, analytics, telemetry, advertisements, cloud storage, or Waves-operated server.

- Local source files are read for metadata and processing and are never modified or uploaded by Waves.
- Generated audio is written only to the destination selected by the user.
- YouTube workflows contact YouTube and related Google image/media hosts through yt-dlp and thumbnail requests. Those services receive normal network information such as the user's IP address.
- Temporary job files are stored in an operating-system temporary directory and removed after success, failure, or cancellation.
- Settings remain in the local macOS application configuration directory.

This document describes the v1.0 local build. Anyone modifying the source is responsible for documenting changed behavior.
